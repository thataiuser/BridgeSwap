# Bridgeswap (class project demo)

A static front-end demo of a crypto buy/swap page. Prices come live from the free CoinGecko API (falls back to simulated prices if the API is unreachable). No payments are processed.

## Deploy on Render
1. Push this folder to a GitHub repo.
2. On render.com: New > Static Site > connect the repo.
3. Build command: leave empty. Publish directory: `.`
4. Click Create Static Site. Your site goes live at `https://<name>.onrender.com`.

(Or use New > Blueprint, which reads `render.yaml` automatically.)
